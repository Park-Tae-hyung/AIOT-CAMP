AIoT가 뭐예요? 큰 그림부터 봐요

AIoT는 AI(인공지능) + IoT(사물인터넷)예요. 물건이 스스로 주변을 느끼고, 상황을 판단하고, 알맞게 반응하고, 필요하면 다른 기기와 연결돼요. 우리가 만들 시제품(프로토타입)도 딱 이 네 칸으로 이루어져요.

2 필요한 데이터 정하기

무엇을 재면 ‘위험’을 알 수 있을까?

기계는 눈치가 없어요. 오직 숫자(데이터)로만 상황을 알아요. 그래서 “어떤 상황이면 어떤 숫자가 어떻게 변할지” 미리 예상해 보는 것이 가장 중요해요. 이것을 데이터 가설이라고 해요.

4 조립하고 연결하기

확장보드에 바르게 꽂기

지니어스 키트의 확장보드는 마이크로비트의 핀을 1번부터 16번까지 쓰기 쉽게 늘려 주는 “멀티탭”이에요. 핀마다 노랑(S 신호) · 빨강(V 전원) · 검정(G 접지) 세 줄이 있어서 3핀 케이블을 색만 맞춰 꽂으면 돼요.

4-1. 확장보드 지도

핀 고르는 규칙 (꼭 지켜요!)

  • 아날로그 센서(조도·온도·토양·가스·가변저항·키패드)는 1번, 2번에 꽂아요. (3·4·10번도 되지만 그러면 LED 화면을 끌 수밖에 없어요.)
  • 디지털 센서·모터·LED·LED 링은 8, 13, 14, 15, 16번을 써요.
  • 5번·11번은 A·B 버튼, 6·7·9번은 LED 화면이 쓰고 있어요. 비워 두세요.
  • 0번은 확장보드의 부저(소리)가 쓰고 있어요.
  • OLED는 핀 번호가 아니라 아래쪽 G·V·CL·DA 4핀 자리에 꽂아요.

방법 ① 실시간 그래프 (USB 연결 중)

      
기본판을 다운로드한 뒤 B 버튼으로 기록을 시작하고, 시뮬레이터 아래의 “데이터 보기(장치)” 버튼을 눌러요. 센서값이 그래프로 그려지고, 오른쪽 위 내려받기(↓) 아이콘을 누르면 CSV 파일로 저장돼요.

      
USB 케이블이 꽂혀 있고 장치 연결(페어링)이 되어 있어야 보여요.

    

    

      
방법 ② 데이터 로거 파일 (데이터 로거판 · V2 전용)

      
기록한 값은 마이크로비트 안에 저장돼요. USB로 꽂으면 파일 탐색기에 MICROBIT 드라이브가 보여요. 그 안의 MY_DATA.HTM을 열면 표가 나오고, Download 버튼으로 CSV를 받을 수 있어요.

      
USB를 빼도, 배터리로 밖에서 측정해도 기록이 남아서 현장 측정에 좋아요.

    

  

  
수학 연결 — 몇 개나 모아야 할까?
  측정값은 매번 조금씩 흔들려요(잡음). 개수가 많을수록 평균이 진짜 값에 가까워져요. 상황마다 최소 10개, 가능하면 20개 이상 모아요. 머신러닝포키즈는 라벨마다 최소 5개(소리는 8개)가 있어야 학습할 수 있어요.

  






  
6 데이터로 판단 규칙 만들기

  
숫자를 보고 ‘기준값’을 정해요

  
모은 CSV 파일을 메모장으로 열어 내용을 아래 칸에 붙여 넣고 [분석하기]를 누르세요. 상황별 평균과 범위를 계산하고, 추천 기준값을 찾아 줘요. 직접 적어도 돼요. 한 줄에 상황,값,값… 형식이에요.

  

    
    
    

    

  


  
6-1. 기준값은 어떻게 정할까?

  

  
수학 연결 — 두 평균의 가운데
  두 상황의 평균 a, b 사이 정확히 가운데는 (a + b) ÷ 2예요(수직선 위 두 점의 중점). 기준값을 위험 쪽으로 옮기면 경보가 덜 울리지만 놓칠 위험이 커지고, 정상 쪽으로 옮기면 빨리 알려 주지만 괜히 울리는 경보(오경보)가 늘어요. 우리 제품에는 무엇이 더 중요할까요? 이것이 9차시의 트레이드오프예요.


  
6-2. 판단을 더 똑똑하게 만드는 3가지 기술

  

    
① 부드럽게 하기 (이동 평균)
값이 한 번 툭 튀어도 바로 반응하지 않도록, 최근 값들을 평균 내서 써요. 코드 생성기의 “부드럽게 하기”를 켜면 돼요.

    
② 연속 확인 (연속 감지)
위험이 3번 연속 나올 때만 위험으로 정해요. 잠깐의 실수로 경보가 울리는 것을 막아요.

    
③ 여러 센서 합치기
“그리고(AND)”: 모든 센서가 위험일 때만 위험 → 오경보 ↓
“또는(OR)”: 하나라도 위험이면 위험 → 놓침 ↓

  

  
수학 연결 — 그리고·또는 = 교집합·합집합
  “온도가 높다” 집합 A, “가스가 많다” 집합 B가 있을 때, “그리고”는 A∩B(교집합), “또는”은 A∪B(합집합)예요. 합집합이 더 크니까 “또는”으로 정하면 경보가 더 자주 울려요.


  
6-3. 상태별 동작 설계표 (5차시)

  
정상·주의·위험일 때 각 장치가 어떻게 움직일지 정해요. 이 표는 STEP 8 코드 생성기에서 그대로 고를 수 있어요. 단계가 올라갈수록 점점 세지게 만들면 사용자가 위험 정도를 바로 느껴요.

머신러닝포키즈(Machine Learning for Kids)는 학생용 무료 AI 학습 사이트예요. 사진·소리·글·숫자를 보여 주면 컴퓨터가 스스로 규칙을 배워요. 설치할 프로그램 없이 웹사이트 + 스크래치 블록만으로 마이크로비트와 연결할 수 있어요.

7-3. 머신러닝포키즈 사용법 — 프로젝트 만들기부터 학습까지

라벨은 AI가 고를 “정답 이름”이에요. 영어 소문자로 짧게 쓰면 블록에서 쓰기 편해요. 마이크로비트 화면에 보일 글자도 함께 정해져요. (주의 라벨은 없으면 비워 두세요.)

    

      

      

      

    

    

  

  


  
7-4. 만든 AI를 마이크로비트에 연결하기 — 스크래치 3 + 마이크로비트

  
가장 쉬운 방법 한 가지: 머신러닝포키즈 스크래치 3 + micro:bit 확장
  파이썬 설치 없이, 머신러닝포키즈가 열어 주는 스크래치 3에서 블록 몇 개로 연결해요. 노트북과 마이크로비트는 블루투스로 연결되니 노트북 블루투스를 켜 두세요. 노트북에 설치할 것은 Scratch Link 하나뿐이에요(선생님이 미리 설치해 두면 더 빨라요).

  

  
알아 두기 — 스크래치 연결 중에는 확장보드를 쓸 수 없어요스크래치용 파일을 넣으면 마이크로비트 안의 MakeCode 코드가 지워져서, 연결하는 동안에는 마이크로비트 화면·버튼·기울기만 써요. 다시 센서·모터 작품으로 돌아가려면 MakeCode에서 우리 코드를 다시 다운로드하면 끝! 발표 때는 “① 센서 작품 시연 → ② AI 판단 시연” 순서로 보여 주거나, 마이크로비트 2개를 나눠 써도 좋아요.


  
7-5. 좋은 AI를 만드는 데이터 규칙

  

    
✅ 균형
라벨마다 데이터 개수를 비슷하게. 정상 50개 : 위험 5개면 AI가 “다 정상”이라고만 말해요.

    
✅ 다양성
밝기·거리·각도·배경·사람·목소리를 바꿔 가며 모아요. 한 상황만 모으면 다른 상황에서 틀려요.

    
✅ 시험용 데이터는 따로
학습에 넣지 않은 새 데이터로 테스트해야 진짜 실력을 알 수 있어요. 10번 중 몇 번 맞혔는지 = 인식률(정확도).

    
✅ 신뢰도 기준 정하기
정확도 블록으로 “70% 이상일 때만 위험 표시”처럼 정하면 실수가 줄어요.

  

  
수학 연결 — 인식률 계산인식률(%) = 맞힌 개수 ÷ 전체 시험 개수 × 100. 위험 상황 10번 중 8번 알아챘다면 80%예요. 정상인데 위험이라고 한 횟수(오경보)도 함께 세어 보세요.


  
7-6. 머신러닝포키즈 vs 티처블 머신 (4차시)

  

    
비교머신러닝포키즈티처블 머신

    
학습할 수 있는 것이미지 · 소리 · 텍스트 · 숫자이미지 · 소리 · 자세

    
마이크로비트 연결스크래치 3 + micro:bit 확장으로 블록만으로 연결별도 코드가 필요

    
계정선생님 학급 계정 · 바로 체험구글 계정(모델 저장 시)

  


  
7-7. 자주 막히는 곳

  

    
증상해결

    
[지금 실행해보기]·[계정 만들기]에서 “로봇이 아닌지 확인” 오류광고 차단 확장 프로그램을 끄거나 다른 브라우저로 해 봐요. 학교망이 막고 있으면 선생님께 말씀드려요. 이미 계정이 있으면 [로그인]은 이 확인 없이 돼요.

    
학습 버튼이 눌리지 않아요라벨마다 최소 개수(이미지·텍스트·숫자 5개, 소리 8개)를 채웠는지 확인해요.

    
스크래치에 우리 AI 블록이 없어요머신러닝포키즈 프로젝트의 만들기 → 스크래치 3으로 열어야 해요. 일반 스크래치 사이트에는 없어요.

    
micro:bit 연결 창에 아무것도 안 보여요① Scratch Link가 켜져 있나요? ② 노트북 블루투스가 켜져 있나요? ③ 스크래치용 HEX를 넣었나요(화면에 5글자 이름이 흘러가요)? ④ 마이크로비트에 전원(USB·배터리)이 들어가 있나요?

    
목록에 다른 팀 마이크로비트가 보여요우리 마이크로비트 화면에 흐르는 5글자 이름만 골라요.

    
웹캠·마이크가 안 켜져요주소창 왼쪽 자물쇠 → 카메라·마이크 허용. 다른 프로그램(줌 등)이 카메라를 쓰고 있으면 꺼요.

    
결과가 자꾸 바뀌어요데이터를 더 다양하게 모아 다시 학습하고, 정확도 70% 이상일 때만 표시하도록 블록을 바꿔요.

    
키트 센서·모터가 안 움직여요스크래치용 HEX가 들어가 있어서 그래요. MakeCode에서 우리 코드를 다시 다운로드해요.

  

  






  
8 코드 생성기

  
빈칸을 채우면 마이크로비트 코드가 완성돼요

  
STEP 1·3·6에서 정한 내용이 이미 들어 있어요. ①~④마다 💡 추천 칸이 우리 아이디어에 맞는 값을 이유와 함께 알려 줘요. [추천 적용]을 누르거나 직접 고치면 아래 코드가 바로바로 바뀌어요. 만들어진 코드는 MakeCode의 자바스크립트 탭에 붙여 넣으면 블록으로도 볼 수 있어요.


  

    
① 판단 방식 고르기

    

      
      
      
🖼·🔊·🔤 사진·소리·글 AI라면?
이 코드가 아니라 STEP 7-4의 스크래치 3 + 마이크로비트로 연결해요. 센서 작품은 여기서 따로 만들어요.

    

    

  


  

    
② 센서와 기준값

    
STEP 3에서 담은 센서가 나와요. 방향은 “값이 커질수록 위험”인지 “작아질수록 위험”인지 골라요. 디지털 센서는 “이 값이면 위험”을 골라요.

    

    

  


  

    
③ 상태별 동작 (정상 · 주의 · 위험)

    
STEP 3에서 담은 출력 장치가 나와요. LED 화면과 소리는 항상 쓸 수 있어요. LED 화면과 OLED에는 영어·숫자만 나와요(한글 ✗).

    

    

  


  

    
④ 그 밖의 설정

    

      

      

      

      

      

    

    

  


  

  

  


  
8-1. MakeCode에 코드 넣기

  
1
makecode.microbit.org → 새 프로젝트이름은 반번호_이름_작품처럼 지어요.

  
2
확장 기능 먼저 추가하기이 코드는 확장 기능이 필요 없어요.

  
3
위쪽 탭에서 [JavaScript] 클릭안에 있는 코드를 Ctrl+A로 모두 고르고 지운 뒤, 복사한 코드를 Ctrl+V로 붙여 넣어요.

  
4
[블록] 탭으로 돌아가 확인코드가 블록으로 바뀌어요. 빨간 경고가 보이면 확장 기능을 추가했는지 확인해요.

  
5
시뮬레이터로 먼저 시험 → 다운로드왼쪽 가상 마이크로비트에서 센서 값을 바꿔 보고, 잘 되면 USB를 꽂고 다운로드해요.

  


  
8-2. 만들어진 코드 읽는 법

  

    
코드 부분하는 일고칠 때

    
// 1. 설정값기준값·모터 세기·서보 각도 같은 숫자 모음보정할 때 여기 숫자만 바꿔요

    
function readSensors()센서값을 읽어 변수에 저장핀 번호가 연결과 같은지 확인

    
function judgeByRule()기준값과 비교해 0(정상)·1(주의)·2(위험) 결정부등호 방향 확인

    
function applyState()상태에 맞게 LED·소리·모터 움직이기동작 바꾸기

    
basic.forever읽기 → 판단 → 반응을 계속 반복측정 간격 바꾸기

  

  
생성형 AI와 함께 고치기
  코드를 ChatGPT·제미나이·클로드에 붙여 넣고 “고1이 이해하도록 이 줄의 뜻을 설명해 줘”, “위험일 때 LED가 깜빡이게 바꿔 줘”처럼 물어보세요. AI가 준 코드는 초안이에요. 시뮬레이터로 꼭 확인해요(6차시 원칙).

  






  
9 업로드하고 테스트하기

  
점검표로 하나씩 확인해요

  
오류는 실패가 아니라 정보예요(7차시). “증상 → 원인 짐작 → 확인 실험 → 해결” 순서로, 한 번에 하나만 바꿔 가며 고쳐요.

  
9-1. 작동 점검표

  
    
  
    9-2. 이럴 땐 이렇게
    
  
    
    
    증상먼저 확인할 것
    
    
    아무 반응이 없어요배터리 스위치 ON? 건전지 방향? 다운로드가 끝까지 됐나요(뒷면 노란 불 깜빡임이 멈춤)?
    
    
    센서값이 0 또는 1023에서 안 움직여요케이블 색(노랑 S·빨강 V·검정 G) 방향, 꽂은 핀 번호 = 코드 핀 번호인지
    
    
    모터·서보가 안 돌아요배터리 연결(USB 전기만으로는 약해요), 출력 핀 번호, 세기 값이 0이 아닌지
    
    
    LED 화면이 꺼져 있어요3·4·10번 핀에 아날로그 센서를 꽂았나요? → 1·2번으로 옮기기
    
    
    경보가 너무 자주 울려요기준값을 위험 쪽으로 옮기기, 부드럽게 하기 켜기, 연속 확인 3번
    
    
    위험인데 반응이 없어요부등호 방향(커질수록/작아질수록) 확인, 기준값을 정상 쪽으로 옮기기
    
    
    스크래치 AI 결과가 마이크로비트에 안 떠요STEP 7-7 “자주 막히는 곳”을 확인해요 (Scratch Link·블루투스·스크래치용 HEX·5글자 이름)
    
    
    코드에 빨간 줄이 생겨요필요한 확장 기능(neopixel·sonar·OLED)을 먼저 추가했는지
    
  
    
  
    9-3. 테스트 기록표
    
  
    
    
    번호연출한 상황기대한 상태실제 상태반응 시간맞음/틀림
    
    
    1평소 상태정상
    
    
    2조금 이상한 상태주의
    
    
    3위험 상태위험
    
    
    …상황마다 5번 이상 반복하고 인식률(%)을 계산해요.
    
  
    
  

    



    
  
    10 제품으로 완성하고 발표하기
    
  
    상자에 넣고, 다시 재고, 자랑하기
    
  
    
    
    📦 하우징 (8차시)
    • 센서 창(구멍)을 센서 바로 앞에
    • USB·배터리 스위치에 손이 닿게
    • 선이 꺾이거나 당겨지지 않게 여유 두기
    • “예쁜 상자”보다 “작동하는 상자”
    
    
    🔧 통합 테스트·보정 (9차시)
    • 상자에 넣은 상태로 다시 측정
    • 기준값을 코드 맨 위 설정값에서 수정
    • 다른 팀이 써 보는 교차 테스트
    • 고치기 전·후 인식률 기록
    
    
    🎤 발표 준비 (10~12차시)
    • 문제 → 해결 → 작동 시연 → 숫자 근거
    • “인식률 85%, 반응 0.4초”처럼 숫자로
    • 한계와 다음 개선 계획도 솔직하게
    • 시연 실패 대비 영상 찍어 두기
